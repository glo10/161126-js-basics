# Atelier 3.1 : les objets du navigateur

## Enoncé

1. Utilisez les boîtes de dialogue pour poser des questions à l'utilisateur et affichez les réponses
2. Affichez l'URL courante dans la console
3. Développez un minuteur d'affichage en console qui se déclenche toutes les secondes grâce à `setInterval` et s'arrête proprement à une valeur cible 60 sécondes avec `clearInterval`.
4. Écrivez un script qui ouvre une nouvelle fenêtre avec `window.open` (en spécifiant ses dimensions), interrogez l'objet `screen` pour vérifier la résolution de l'écran, et fermez la fenêtre automatiquement après un délai.
