# Atelier 1.1 : introduction

## Enoncé

1. Créez un nouveau nommé CV par exemple
2. Créez un fichier html contenant votre nom, prénom, profession, formations et vos loisirs en utilisant les balises suivantes :
- header (identité)
- main (profession et formations)
- p : balise paragraphe
- ul et li : pour les listes non ordonnées
- ol et li : pour les listes ordonnées
- h1 : titre de niveau 1 (importance la plus élévée), un seul page page web
- h2 : titre de niveau 2, 0, 1 ou plusieurs selon son contenu
- h3 : titre niveau 3
- h4 : titre niveau 4
- h5 : titre niveau 5
- h6 : titre niveau 6
- a et l'attribut href pour un lien interne ou externe
- footer (les loisirs)
3. Mettre un lien vers un CSS externe avec le contenu
```css
body {
    background-color: lightgreen;
}
```
4. Mettre un lien vers un JS externe avec le contenu
```javascript
alert('Hello world');
```
