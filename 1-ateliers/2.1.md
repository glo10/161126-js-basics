# Atelier 2.1 : JavaScript, le coeur du langage : les scopes

## Enoncé

1. Dans les codes ci-dessous, sans exécuter le programme, donnez les valeurs finales des variables déclarées avec let, const ou var.

**Que valent x, y, config, i et j ?**

```javascript
let x = 10;
var y = 20;

if (true) {
  let x = 30;
  var y = 40;
  console.log(x);
  console.log(y);
}

console.log(x);
console.log(y);
```

```javascript
const config = { mode : "debug", retries : 3 };

function updateConfig() {
  const config = { mode : "production", retries : 5 };
  config.retries = 10;
  console.log(config.retries);
}

updateConfig();
console.log(config.mode);
console.log(config.retries);
```

```javascript
for (var i = 0; i < 3; i++) {
  setTimeout(() => {
    console.log(i);
  }, 10);
}

for (let j = 0; j < 3; j++) {
  setTimeout(() => {
    console.log(j);
  }, 20);
}
```
